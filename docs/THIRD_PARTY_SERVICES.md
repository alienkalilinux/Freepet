# Сторонние сервисы и SDK

Документ описывает все внешние сервисы, которые могут получать данные
пользователей ФРИПЕТ, зачем они нужны и как ограничено их использование.

Актуально на 09.11.2026. При добавлении новой библиотеки, CDN, аналитики или
API обновите этот документ, политику конфиденциальности и, если нужно, баннер
согласия.

## Принципы

1. **Минимум данных.** Передаётся только то, без чего функция не работает.
2. **Согласие.** Внешние карты и резервный геокодер загружаются только после
   явного согласия в баннере cookie.
3. **Нет скрытой аналитики.** На сайте нет Яндекс.Метрики, Google Analytics,
   пикселей соцсетей, рекламных сетей и A/B-инструментов.
4. **Нет продажи данных.** Персональные данные не продаются и не передаются
   для таргетированной рекламы.

## Подробности

### Яндекс Карты

- Компоненты: `frontend/src/components/YandexMap.tsx`,
  `frontend/src/components/MapPicker.tsx`, `frontend/src/components/LocationModal.tsx`.
- Ключ: `NEXT_PUBLIC_YANDEX_MAPS_KEY`.
- Согласие: `useConsent('external')`. До согласия карта не загружается,
  показывается уведомление, город можно выбрать вручную.
- Отзыв: кнопка «Настройки cookie» в подвале; после отзыва карта не
  загружается при следующем открытии страницы.
- Картографические данные предоставляет Яндекс на условиях его лицензий.

### Nominatim (OpenStreetMap)

- Компонент: `frontend/src/lib/ymapsUtils.ts`.
- Используется как резервный геокодер, если Яндекс-геокодер вернул ошибку или
  недоступен.
- Запросы выполняются только из компонентов, которые уже открыты после
  согласия на внешние карты.
- Передаются только координаты или название города; данные аккаунта не
  передаются.
- Данные OpenStreetMap распространяются по лицензии ODbL 1.0.

### Mail.ru OAuth

- Backend: `backend/services/mailru.py`, `backend/routers/auth.py`.
- Пользователь сам инициирует вход через Mail.ru.
- Передаются идентификатор, имя и email, которые возвращает провайдер.
- Пароль от Mail.ru сайту не передаётся.

### Brevo / Gmail SMTP

- Backend: `backend/services/email.py`.
- Используются для служебных писем: код подтверждения, восстановление доступа,
  уведомления по аккаунту.
- Приоритет: Brevo API → Gmail SMTP → вывод кода в консоль в демо-режиме.
- В письмах есть ссылки на политику конфиденциальности и удаление данных.
- Массовых рекламных рассылок сейчас нет. Маркетинговое согласие хранится
  отдельно и может быть отозвано в кабинете.

### SMS.ru

- Backend: `backend/services/sms.py`.
- Используется только если задан `SMS_API_KEY` и пользователь указал телефон.
- Передаются номер телефона и текст сообщения с кодом.
- Без ключа код выводится в консоль сервера (демо-режим), наружу не уходит.

### Hugging Face Inference API

- Backend: `backend/services/moderation.py`.
- Модели: `Falconsai/nsfw_image_detection` и
  `google/vit-base-patch16-224`.
- При загрузке фото животного файл отправляется на проверку NSFW и наличия
  животного. Данные аккаунта, email и телефон не передаются.
- Если сервис недоступен, модерация не блокирует загрузку, но может быть
  выполнена вручную.

### Хостинг и инфраструктура

- `frontend/next.config.js` предполагает размещение фронтенда на Vercel и
  проксирование API на Render. Уточните фактических провайдеров и регион
  обработки перед публикацией политики.
- База данных: SQLite для локальной разработки или PostgreSQL
  (`asyncpg`) в рабочей среде.
- Загруженные файлы хранятся в `backend/uploads` или в хранилище хостинга.
- Доступ к административным функциям ограничен ролью.

## Что не используется

- Яндекс.Метрика, Google Analytics, Google Tag Manager;
- пиксели Facebook, VK, TikTok и других соцсетей;
- рекламные сети и ретаргетинг;
- платёжные виджеты и формы приёма карт;
- сторонние чаты и виджеты поддержки;
- A/B-тесты, собирающие поведение;
- внешние шрифты через CDN (Inter подключается через `next/font`).

## Проверка перед добавлением сервиса

1. Определите, какие данные сервис получает и зачем.
2. Проверьте, можно ли обойтись без него или минимизировать данные.
3. Если сервис необязателен, добавьте отдельную категорию согласия.
4. Обновите `/legal/privacy`, `/legal/cookies`, `/legal/licenses` и этот файл.
5. Укажите срок хранения и регион обработки.
6. Проверьте, что отзыв согласия действительно останавливает загрузку.
