# Настройка юридических документов и приватности

Практическая инструкция для владельца и администратора ФРИПЕТ: какие
переменные заполнить, как менять версию согласий и как обрабатывать запросы
пользователей.

## 1. Переменные окружения фронтенда

Скопируйте `frontend/.env.example` в `frontend/.env.local` и заполните
значения. Переменные `NEXT_PUBLIC_*` встраиваются в сборку, поэтому после
изменения нужен перезапуск dev-сервера или новая сборка.

| Переменная | Назначение | Обязательность |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | публичный адрес сайта | рекомендуется |
| `NEXT_PUBLIC_LEGAL_OPERATOR` | полное наименование оператора | да, для реквизитов |
| `NEXT_PUBLIC_LEGAL_FORM` | организационно-правовая форма (ИП, ТОО, АО) | да |
| `NEXT_PUBLIC_LEGAL_BIN` | БИН или ИИН | да |
| `NEXT_PUBLIC_LEGAL_ADDRESS` | юридический/фактический адрес | да |
| `NEXT_PUBLIC_LEGAL_PHONE` | телефон для официальных обращений | нет |
| `NEXT_PUBLIC_LEGAL_JURISDICTION` | юрисдикция | нет, по умолчанию Казахстан |
| `NEXT_PUBLIC_LEGAL_EMAIL` | общие вопросы и официальные обращения | да |
| `NEXT_PUBLIC_PRIVACY_EMAIL` | запросы по персональным данным | да |
| `NEXT_PUBLIC_SUPPORT_EMAIL` | поддержка и жалобы | да |
| `NEXT_PUBLIC_YANDEX_MAPS_KEY` | ключ JavaScript API Яндекс.Карт | нет |

Пока реквизиты не заполнены, `/legal/requisites` показывает «не указано» и
предупреждение. Это сделано намеренно: сайт не должен выдумывать данные
оператора.

## 2. Переменные окружения бэкенда

Файл `backend/.env` (см. `backend/.env.example`). Значения по умолчанию
предназначены только для локальной разработки.

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | строка подключения к базе данных |
| `SECRET_KEY` | подпись JWT; обязательно замените в рабочей среде |
| `FRONTEND_URL` | публичный адрес фронтенда для ссылок в письмах |
| `FRONTEND_ORIGIN` | разрешённые origin для CORS (через запятую) |
| `BACKEND_URL` | публичный адрес API |
| `EMAIL_HOST`, `EMAIL_PORT` | SMTP-сервер |
| `EMAIL_USER`, `EMAIL_PASSWORD`, `EMAIL_FROM` | учётные данные SMTP |
| `BREVO_API_KEY` | ключ Brevo (приоритетный способ отправки) |
| `SMS_API_KEY` | ключ SMS.ru |
| `MAILRU_CLIENT_ID`, `MAILRU_CLIENT_SECRET`, `MAILRU_REDIRECT_URI` | вход через Mail.ru |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_EMAIL` | администратор; смените пароль |
| `TEST_USERNAME`, `TEST_PASSWORD`, `TEST_EMAIL` | тестовый аккаунт; отключите в рабочей среде |

## 3. Версия согласий

Версия указана в `frontend/src/lib/legal.ts`:

```ts
export const CONSENT_VERSION = '2026-11-09';
export const LEGAL_UPDATED_AT = '09.11.2026';
```

При изменении текста политики, оферты или состава обрабатываемых данных:

1. Измените дату в `LEGAL_UPDATED_AT`.
2. Измените `CONSENT_VERSION` на новую дату.
3. Обновите дату в юридических страницах, где она упоминается.
4. Проверьте, что регистрация передаёт новую версию на бэкенд.
5. При существенных изменениях запросите согласие повторно у действующих
   пользователей (например, баннером или уведомлением в кабинете).

Сервер хранит `consent_version` и `consent_at` для каждого пользователя,
поэтому по записи можно доказать, какую редакцию документов принял человек.

## 4. Обработка запросов пользователей

### Доступ и копия данных

- Пользователь может скачать JSON в кабинете: «Мои данные и согласия» →
  «Скачать данные».
- API: `GET /api/account/export`.
- Если нет доступа к аккаунту — запрос на `NEXT_PUBLIC_PRIVACY_EMAIL`.
- Срок ответа: 10 рабочих дней, если закон не требует иного.

### Исправление данных

- Профиль и анкеты редактируются в кабинете.
- Если поле нельзя изменить самостоятельно, пользователь пишет на
  `NEXT_PUBLIC_PRIVACY_EMAIL`.

### Удаление аккаунта

- Кабинет → «Мои данные и согласия» → «Удалить аккаунт» → пароль.
- API: `DELETE /api/account` с телом `{ "password": "..." }`.
- Для входа через Mail.ru без пароля — запрос на `NEXT_PUBLIC_PRIVACY_EMAIL`
  с подтверждением владения аккаунтом.
- После удаления пользователь разлогинивается; localStorage браузера нужно
  очистить отдельно (инструкция на `/legal/data-deletion`).

### Отписка от рассылок

- Кабинет → «Мои данные и согласия» → переключатель рассылок.
- API: `PUT /api/account/consents` с `{ "marketing_consent": false }`.
- Согласие на сервисные письма (коды, безопасность) отозвать нельзя, пока
  действует аккаунт: без них нельзя подтвердить вход.

### Жалобы и обращения

- Поддержка: `NEXT_PUBLIC_SUPPORT_EMAIL`.
- Правообладатели: `NEXT_PUBLIC_LEGAL_EMAIL` с темой «Правообладатель».
- Официальные обращения: `NEXT_PUBLIC_LEGAL_EMAIL`.
- Барьеры доступности: `NEXT_PUBLIC_SUPPORT_EMAIL`.

## 5. Сроки хранения

Ориентиры, указанные в политике и на странице удаления:

| Категория | Срок |
| --- | --- |
| Данные аккаунта | до удаления аккаунта или отзыва согласия |
| Анкеты животных | до удаления анкеты или аккаунта |
| Сообщения | до 12 месяцев после последней активности |
| Жалобы и обращения | до 12 месяцев после закрытия |
| Записи о согласиях | 3 года |
| Технические журналы | до 90 дней |
| Резервные копии | до 30 дней после удаления |

Если закон требует хранить данные дольше, обработка ограничивается только
целью исполнения обязанности.

## 6. Почта и уведомления

- Настройте Brevo или SMTP, иначе коды подтверждения выводятся в консоль
  сервера (демо-режим).
- В письмах уже есть ссылки на политику и удаление данных.
- Укажите реальные адреса `NEXT_PUBLIC_PRIVACY_EMAIL` и
  `NEXT_PUBLIC_SUPPORT_EMAIL`, которые проверяются.
- Не отправляйте пароли и коды в открытом виде повторно.

- [ ] Юридические тексты проверены юристом по законодательству Казахстана.
- [ ] Проведён аудит доступности WCAG 2.1 AA / ГОСТ Р 52872-2019.

      добавлялись сервисы.

## 8. Юридические оговорки

- Документы описывают текущую функциональность: бесплатную платформу без
  платежей, комиссий, отзывов и массовых рассылок.
- Если появится платная функция, платёжный провайдер, аналитика или новый
  внешний сервис, документы и согласия нужно обновить **до** запуска.
- Тексты составлены по общим требованиям Закона Республики Казахстан
  № 94-V «О персональных данных и их защите», Закона «О защите прав
  потребителей» в применимой части и ориентира WCAG 2.1 AA /
  ГОСТ Р 52872-2019. Это не заменяет индивидуальную юридическую консультацию.
